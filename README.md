## 🗺️ My Learning Roadmap

### 🔥 Phase 1 — Programming Foundations

- [ ] **Data Structures & Algorithms (DSA)**
  - Arrays, strings, hashing, two pointers, sliding window
  - Recursion, backtracking, linked lists, stacks, and queues
  - Trees, BSTs, heaps, graphs, BFS, DFS, and shortest paths
  - Dynamic programming, greedy algorithms, binary search, tries, and bit manipulation

- [ ] **Core Programming Language — Java**
  - Core Java, Collections Framework, OOP, exceptions, and clean coding
  - Problem-solving and writing code independently
  - Explore C++ and STL if needed for future learning

- [ ] **Git, GitHub & Software Engineering**
  - Git commands, branches, pull requests, and merge conflicts
  - Code reviews, debugging, testing, and clean code
  - CI basics, GitHub Actions, and Agile/Scrum fundamentals

- [ ] **Linux, Shell & Developer Tools**
  - Command-line usage and Bash scripting
  - File permissions, processes, SSH, grep, sed, and awk
  - Debugging, logs, and terminal-based workflows

- [ ] **Mathematics for Computer Science**
  - Discrete mathematics, combinatorics, and modular arithmetic
  - Probability, graph theory, and linear algebra fundamentals

### 💻 Phase 2 — Core Computer Science

- [ ] **Operating Systems**
  - Processes, threads, CPU scheduling, and synchronization
  - Mutexes, semaphores, deadlocks, memory management, and paging
  - Virtual memory and file systems

- [ ] **DBMS & SQL**
  - ER models, normalization, and relational databases
  - SQL queries, joins, indexing, transactions, and ACID properties
  - Query optimization, window functions, MongoDB, and Redis fundamentals

- [ ] **Object-Oriented Programming & Low-Level Design**
  - Encapsulation, inheritance, abstraction, and polymorphism
  - SOLID principles and design patterns
  - Design exercises: parking lot, elevator, and library management system

- [ ] **Computer Networks**
  - OSI and TCP/IP models
  - TCP vs UDP, HTTP/HTTPS, DNS, TLS, and sockets
  - Load balancers and the complete journey of a web request

### 🌐 Phase 3 — Development & Real-World Projects

- [ ] **Backend & Web Development**
  - HTML, CSS, and JavaScript
  - Explore React with Node.js and Express, or Spring Boot with Java
  - Explore Django or FastAPI with Python
  - REST APIs, authentication, JWT/OAuth, caching, and message queues

- [ ] **Real-World Projects**
  - Build 2–3 useful projects with clear documentation
  - Develop a full-stack application with authentication and a database
  - Build a backend or systems-oriented project
  - Explore an AI/ML or LLM-powered application
  - Deploy projects and add appropriate tests

- [ ] **Cloud Computing & DevOps**
  - Explore AWS, Google Cloud Platform, and Microsoft Azure
  - Cloud compute, storage, databases, and IAM
  - Docker, Kubernetes fundamentals, and CI/CD
  - Deploy and maintain projects on cloud infrastructure

### 🤖 Phase 4 — AI & Advanced Engineering

- [ ] **AI, Machine Learning & Generative AI**
  - Python, NumPy, and pandas
  - Regression, classification, and model evaluation
  - Neural network fundamentals
  - LLM APIs, prompt engineering, and Retrieval-Augmented Generation (RAG)
  - AI coding tools and verification of generated code

- [ ] **High-Level System Design**
  - Scalability, caching, and load balancing
  - Sharding, replication, queues, streams, and CDNs
  - CAP theorem and distributed system fundamentals
  - Design a URL shortener, rate limiter, chat application, and news feed

- [ ] **Choose a Specialization**
  - Explore backend engineering, cloud/DevOps, AI/ML, or systems programming
  - Choose one area based on my interests and practical experience
  - Build a focused project to develop deeper expertise

- [ ] **Cybersecurity Fundamentals**
  - Basic security principles and common web vulnerabilities
  - Authentication, authorization, and secure coding
  - Safe handling of sensitive information and application security
